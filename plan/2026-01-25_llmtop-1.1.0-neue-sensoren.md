# Plan: llmtop 1.1.0 — RAM %, VRAM %, GPU Power W als Balken

## Zielsetzung
Neue Version `llmtop v1.1.0` mit drei zusätzlichen Sensoren in TUI und `--once`-Modus:
- **RAM %** (direkt nach CPU-Balken): Nutzung aus `/proc/meminfo`, Anzeige `X.X% Y.Y GiB / Z.Z GiB`
- **VRAM % pro GPU** (nach bestehender GPU-Util-Zeile): NVIDIA (`memory.used/memory.total`) oder sysfs (`mem_info_vram_used/total`)
- **GPU Power W pro GPU**: NVIDIA (`power.draw`, Obergrenze `power.limit`→`power.max_limit`→100W-Fallback) oder AMD (hwmon sysfs, Mikrowatt → Watt)

## Scope-Zaun (streng eingehalten)
- Nur `llmtop.py` geändert (eine Datei, Standardbibliotheken, Python 3.12-kompatibel)
- Keine neuen CLI-Optionen (außer `--version` bleibt), keine Layout-Konflikte
- **Bestehende Findings 1–9 aus `status.md` bleiben unverändert dokumentiert** (nicht behoben!)
- Keine Nebenänderungen (Refactoring, Code-Optimierung, neue Dateien außer Dokumentation)

## Datenquellen & Formeln
| Sensor | Quelle NVIDIA | Quelle AMD/sysfs | Rechnung |
|--------|---------------|------------------|----------|
| RAM % | — | `/proc/meminfo` | `(MemTotal - MemAvailable) / MemTotal * 100` |
| VRAM % | `memory.used/memory.total` (MiB) | `{<gpu>/device/mem_info_vram_used,mem_info_vram_total}` (Bytes→MiB) | `used/total * 100` |
| Power W | `power.draw` (Float) | `{<gpu>/device/hwmon/hwmon*/name=="amdgpu"}/power1_input` (µW÷1e6) | `draw/limit * 100` |

- VRAM/MiB: integer Format
- Power/Watt: eine Nachkommastelle, GPU-Namen in Balken-Titel (NVIDIA/GPU0, etc.)

## Anzeigereihenfolge (TUI und `--once` identisch)
1. Header (os_name, version, llmtop_build_type)
2. Host-URL (aus `OLLAMA_HOST`, Default 11434)
3. Ollama-Status (API-Fehler oder Modellblock)
4. CPU-Balken + Label (`[CPU] Load: 0.5 / 4.2` etc.)
5. **RAM-Zeile**: `RAM  [BALKEN] 23.9%  7.3 GiB / 30.5 GiB`
6. Modellblock (aus Ollama-API, wenn verfügbar)
7. GPU-Zeilen (bestehend: `[GPU] Util: 45%`)
8. **VRAM+Power-Zeile pro GPU** (mit zweispitziger Einrückung): `  VRAM [BALKEN] 91.3%  7441 / 8151 MiB  Power [BALKEN] 59.8 W / 115 W`
9. Quellenkette, Intervall-Zeile, Help-Zeile

## Balken-Spezifikation
- CPU/RAM: `max(6, min(24, w - 30))` Breite
- VRAM+Power pro GPU: jeweils `max(6, min(12, w - 54))`, beide in einer Zeile mit zwei Leerzeilen Einrückung
- Balkenfarben: `<50% Grün, <80% Gelb, sonst Rot`, leer bei `None`

## Fehlende Werte behandeln
- VRAM/Power `n/a`: Text ohne Balken (kein Traceback, Exit 0)
- Kein Formatieren von `None` (keine `.3d`-Fehler oder Abstürze)
